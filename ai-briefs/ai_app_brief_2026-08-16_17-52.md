## 新产品 / 新工具

**Chert**（Product Hunt）
- 链接：https://www.producthunt.com/products/chert
- 方向：Agent / 自动化工作流

**为什么值得关注**：号称“FaceTime 版的 Vapi”，几行代码就能接入 AI 视频 Agent。视频通话场景的客服、陪伴、远程指导类应用，开发门槛被压到很低。

---

**HarnessRouter 社区版**（Product Hunt）
- 链接：https://www.producthunt.com/products/epsilla
- 方向：Agent / 自动化工作流

**为什么值得关注**：给 Agent harness 做统一接口的开源方案。现在 Agent 框架太多，团队想切换或对比成本很高，这类路由层正好解决“被单一框架绑死”的问题。

---

**CostLogic**（Product Hunt）
- 链接：https://www.producthunt.com/products/costlogic
- 方向：多模态 / 内容生产

**为什么值得关注**：AI 自动做工程算量、估价和发票。建筑行业长期靠人工翻图纸算钢筋水泥，这工具等于把最枯燥的流程自动化，工程预算员的日常可能要变。

---

**Blume**（Product Hunt）
- 链接：https://www.producthunt.com/products/blume-3
- 方向：AI 应用观察

**为什么值得关注**：AI 原生的 Markdown 文档框架。AI 生成内容越来越碎片化，文档工具需要重新设计。对写技术文档、维护内部知识库的团队是个值得试试的新选项。

---

**Inferock Bench**（Product Hunt）
- 链接：https://www.producthunt.com/products/inferock-bench
- 方向：模型能力 / 应用底座

**为什么值得关注**：给每次 LLM API 调用提供独立凭证，解决“怎么证明这个回答来自哪个模型、有没有被改过”的问题。合规审计、模型追溯场景会用到。

---

**Port22**（Product Hunt）
- 链接：https://www.producthunt.com/products/port22
- 方向：开发工具 / 工程效率

**为什么值得关注**：把 Claude Code、Codex 搬到手机上。通勤路上也能盯 Agent 跑任务、改代码，远程开发的体验升级。
