## 新产品 / 新工具

### ZooData – 为 AI Agent 提供数据层的产品  
[ZooData](https://www.producthunt.com/products/zoodata)  
**为什么值得关注**：专为 AI Agent 设计的数据中间层，解决 Agent 运行时数据获取、存储、同步问题。如果你在构建多 Agent 系统，这个工具可能省很多事。

### Clark – 拥有独立云电脑的 AI 同事  
[Clark](https://www.producthunt.com/products/clark-agent)  
**为什么值得关注**：一个 AI 代理，自带云电脑环境，可以执行复杂任务（跑脚本、操作文件）。相当于给每个 Agent 配了一台虚拟机，适合自动化工作流。

### DocuSmart AI – 碎片知识变单一系统  
[DocuSmart AI](https://www.producthunt.com/products/docusmart-ai)  
**为什么值得关注**：企业知识库混乱的救星——把分散的文档、笔记、聊天记录整合为统一可查询系统，RAG 落地的 0 代码方案。

### Buzzy – 你的创意 AI 联合导演  
[Buzzy](https://www.producthunt.com/products/buzzy-2)  
**为什么值得关注**：用 AI 辅助创意生成（视频、文案、故事板），适合内容创作团队提效。

### OpenMarkdown – 你与 AI 共同编辑的 Markdown 编辑器  
[OpenMarkdown](https://www.producthunt.com/products/openmarkdown)  
**为什么值得关注**：本质是“人机协作编辑器”，Agent 和真人可以同时修改同一个 Markdown 文件，适合写文档、做笔记的场景。

### Kimi K3 – 世界首个开源 3T 类模型  
[Kimi K3](https://www.producthunt.com/products/kimi-ai-assistant)  
**为什么值得关注**：Moonshot 发布 3T 参数开源模型，国内大模型首次触及这个量级。可本地部署，对需要私有化大模型的团队很有吸引力。

## 开源项目 / 工程落地

### RAGFlow – 开源 RAG 引擎 + Agent 能力  
[infiniflow/ragflow](https://github.com/infiniflow/ragflow) ⭐ 85k  
**为什么值得关注**：成熟的企业级 RAG 方案，内置 Agent 工作流，支持对话、搜索增强。适合想快速搭建知识库问答系统的团队。

### Unsloth – 在 Web UI 里本地训练开源模型  
[unslothai/unsloth](https://github.com/unslothai/unsloth) ⭐ 68k  
**为什么值得关注**：Unsloth Studio 提供图形界面，让你在本机训练/运行 Gemma 4、Qwen3.6、DeepSeek 等模型。降低微调门槛。

### AstrBot – 集成 IM、LLM、插件的 AI 代理框架  
[AstrBotDevs/AstrBot](https://github.com/AstrBotDevs/AstrBot) ⭐ 36k  
**为什么值得关注**：一个“开源的闭源替代”，支持微信、飞书、钉钉等 IM 平台，内置插件系统和 AI 功能。适合做聊天机器人的团队。

### Sim – 构建、部署和编排 AI Agent  
[simstudioai/sim](https://github.com/simstudioai/sim) ⭐ 29k  
**为什么值得关注**：把多个 Agent 组合成工作流，类似 Agent 编排的“操作系统”。如果你需要管理多个 Agent 协同，这是当下最火的工具之一。

### Obsidian 第二大脑 – AI 优先的跨 CLI 知识管理  
[eugeniughelbur/obsidian-second-brain](https://github.com/eugeniughelbur/obsidian-second-brain) ⭐ 3.3k  
**为什么值得关注**：让你的 Obsidian 笔记能被 Claude Code、Codex、Gemini 等 AI 工具实时读取和编辑，实现“AI 优先的第二大脑”。

### OpenOSINT – AI 驱动的开源情报 Agent  
[OpenOSINT/OpenOSINT](https://github.com/OpenOSINT/OpenOSINT) ⭐ 1k  
**为什么值得关注**：带有交互式 REPL 和 MCP 服务器的 OSINT 工具，支持 Claude、GPT-4 或本地模型，适合安全研究人员。
