## 开源项目 / 工程落地

**NousResearch/hermes-agent**  
“与你一起成长的 Agent”，已 22 万+ stars。  
→ 为什么值得关注：通用 Agent 框架，支持持续学习，适合做个人助手或对话系统底座。  
[GitHub](https://github.com/NousResearch/hermes-agent)

**infiniflow/ragflow**  
开源 RAG 引擎，融合 Agent 能力，86k+ stars。  
→ 为什么值得关注：RAG 仍是落地主流，结合 Agent 后能处理更复杂任务。  
[GitHub](https://github.com/infiniflow/ragflow)

**nexu-io/open-design**  
开源 Claude Design 替代品，本地优先，让 coding agent 变成设计引擎。  
→ 为什么值得关注：UI 生成工具开源化，降低设计门槛，适合前端团队。  
[GitHub](https://github.com/nexu-io/open-design)

**mem0ai/mem0**  
通用记忆层 for AI Agents，62k stars。  
→ 为什么值得关注：Agent 记忆是持久化对话的关键，跨 session 记忆有实用场景。  
[GitHub](https://github.com/mem0ai/mem0)

**jackwener/OpenCLI**  
把任意网站变成 CLI，AI agent 可通过你已登录的浏览器执行。  
→ 为什么值得关注：简化 agent 与 Web 交互，绕过 API 限制。  
[GitHub](https://github.com/jackwener/OpenCLI)

**vercel/ai**  
TypeScript 的 AI 工具包，25k+ stars。  
→ 为什么值得关注：Next.js 团队出品，前端开发者构建 AI 应用的首选库。  
[GitHub](https://github.com/vercel/ai)
