## 开源项目 / 工程落地

**open-design**（GitHub 78k stars）
👉 [仓库](https://github.com/nexu-io/open-design)
为什么关注：**Claude Design 的开源替代**，本地优先的桌面应用。你的编码 Agent 直接变成设计引擎，输出原型、落地页、图标，设计师和开发者都能用。

**LightRAG**（GitHub 37.7k stars）
👉 [仓库](https://github.com/HKUDS/LightRAG)
为什么关注：简单、快速的 RAG 框架，已接收至 EMNLP2025。**不像传统 RAG 那么重**，轻量好用，适合快速接入知识库。

**Haystack**（GitHub 25.9k stars）
👉 [仓库](https://github.com/deepset-ai/haystack)
为什么关注：生产级 LLM 应用编排框架，支持**模块化 pipeline 和 Agent**。很多公司直接用它搭客服、搜索系统，生态成熟。

**Opik**（GitHub 20.6k stars）
👉 [仓库](https://github.com/comet-ml/opik)
为什么关注：LLM 应用的可观测性工具——**debug、评估、监控**一体化。RAG 和 Agent 工作流遇到问题时，用它追踪调用链找原因。

**ai-berkshire**（GitHub 13.1k stars）
👉 [仓库](https://github.com/xbtlin/ai-berkshire)
为什么关注：基于 Claude Code / Codex 的**价值投资研究框架**，多 Agent 并行分析。中文项目，金融量化领域可以借鉴 Agent 协作模式。

**Presenton**（GitHub 9k stars）
👉 [仓库](https://github.com/presenton/presenton)
为什么关注：**开源 AI 演示生成器**，对标 Gamma/Canva。如果你不想用闭源产品，这个可以自部署，支持 API。
