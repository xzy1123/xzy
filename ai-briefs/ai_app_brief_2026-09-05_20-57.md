**链接**：https://www.producthunt.com/products/gitwarren

### Hyperprobe
**链接**：https://www.producthunt.com/products/hyperprobe

开源 AI 网关，把流量转化成为训练更好模型的数据。这个思路很实用——不额外造数据，用真实请求反哺模型。

### dif.sh

## 📦 开源项目：想自己动手的看这里

### Codewhale（41k stars）
**链接**：https://github.com/Hmbown/Codewhale

终端里的开源编程 Agent，Rust 编写。如果你不想用云服务，希望在本地跑一个听话的 Agent，这是目前社区很活跃的选择。

### wigolo（5k stars）
**链接**：https://github.com/KnockOutEZ/wigolo

主打“本地优先”的 Agent 搜索/抓取/研究工具，通过 MCP 协议工作。关键卖点：**不需要 API key，无云端依赖，每次查询 $0**。开源免费的 Agent 工具链越来越完整了。

### opensquilla（6.9k stars）
**链接**：https://github.com/TokenRhythm/opensquilla

号称“同等预算下更高的智能密度”——翻译一下：花同样的 token 钱，拿到更好的效果。想给 API 成本瘦身的团队可以关注。

### LangWatch（3.5k stars）
**链接**：https://github.com/langwatch/langwatch

LLM 评估与 Agent 测试平台。很多项目上线前最缺的就是“怎么测、怎么评”，这个工具就是在补这个短板。

### DEEIX-Chat（1.4k stars）
**链接**：https://github.com/DEEIX-AI/DEEIX-Chat

企业级 AI 工作区：模型路由、多模态对话、文件、工具、计费、身份管理一锅端。适合想在公司内部搭统一 AI 入口的团队。
