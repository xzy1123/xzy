## 新产品 / 新工具

**Bluerails Discovery**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/bluerails-discovery)  
**为什么值得关注**：为 AI Agent 提供“支付轨道”——Agent 完成任务后自动找到并付款给用户。场景包括自动报销、任务结算等，打通 Agent 经济闭环。

**Jotform AI App Builder**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/jotform)  
**为什么值得关注**：用自然语言描述需求，几秒生成功能完整的应用。适合非技术人员快速原型验证，或开发团队做 MVP 测试。

**Latitude**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/latitude-4)  
**为什么值得关注**：定位“AI Agent 的调试器”，监控 Agent 运行、定位失败原因。对正在搭建生产级 Agent 的团队来说，是必备的运维工具。

**Buddy AI Note**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/buddy-ai-note)  
**为什么值得关注**：每日备忘录自动变成行动计划，AI 提取待办并排期。适合个人效率提升，也可看作“AI 笔记+任务管理”的轻量融合。

**jebi**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/jebi-the-terminal-that-thinks-with-you)  
**为什么值得关注**：Mac 终端内置本地 AI，无需联网即可在命令行里问问题、生成命令、分析输出。开发者操作效率提升，数据隐私更安全。

**Deckwise**（Product Hunt）  
→ [链接](https://www.producthunt.com/products/deckwise)  
**为什么值得关注**：AI 演示文稿 Agent，直接输出可编辑的幻灯片。与传统 AI 生成 PPT 不同，它保留编辑能力，适合需要频繁调整内容的商务场景。

## 开源项目 / 工程落地

**🤗 Transformers**（GitHub 161k stars）  
→ [链接](https://github.com/huggingface/transformers)  
**为什么值得关注**：Hugging Face 的核心模型库，支持文本、视觉、音频、多模态。最新更新持续覆盖主流架构，是任何 AI 应用开发的“编译器”级别依赖。

**infiniflow/ragflow**（GitHub 83k stars）  
→ [链接](https://github.com/infiniflow/ragflow)  
**为什么值得关注**：RAGFlow 把 RAG 和 Agent 能力融合，提供一站式知识库检索+推理链路。已有大量企业案例（客服、文档问答），部署文档完善。

**microsoft/ai-agents-for-beginners**（GitHub 67k stars）  
→ [链接](https://github.com/microsoft/ai-agents-for-beginners)  
**为什么值得关注**：微软官方出品的 Agent 入门课程，12 节课涵盖原理、框架、实践。适合想系统学习 Agent 开发的团队快速上手。

**santifer/career-ops**（GitHub 55k stars）  
→ [链接](https://github.com/santifer/career-ops)  
**为什么值得关注**：AI 驱动的求职系统，基于 Claude Code 实现 14 种技能模式、生成简历、批量投递。可视为 Agent 在个人场景的标杆应用。

**Tencent/WeKnora**（GitHub 17k stars）  
→ [链接](https://github.com/Tencent/WeKnora)  
**为什么值得关注**：腾讯开源的 LLM 知识平台，将原始文档转化为可查询的 RAG、自主推理 Agent 和自动维护 Wiki。一手对接中文文档，适合企业内部知识库搭建。

**openvinotoolkit/openvino**（GitHub 10k stars）  
→ [链接](https://github.com/openvinotoolkit/openvino)  
**为什么值得关注**：Intel 出品的推理优化工具，支持模型压缩、部署至 CPU/GPU/N
