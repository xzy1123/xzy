## 开源项目 / 工程落地

**hermes-agent**
[链接](https://github.com/NousResearch/hermes-agent)
为什么值得关注：主打“随你成长”的 Agent 框架，社区热度很高。想自建 Agent 底座可以先看它的设计取舍。

**langflow**
[链接](https://github.com/langflow-ai/langflow)
为什么值得关注：可视化搭 Agent 和工作流的老牌项目，适合快速做原型给业务方看。

**claude-mem**
[链接](https://github.com/thedotmack/claude-mem)
为什么值得关注：解决 Agent 跨会话“失忆”问题——记录、压缩、再注入上下文。长期跑 Agent 的团队几乎都会撞上这个坑。

**qwen-code**
[链接](https://github.com/QwenLM/qwen-code)
为什么值得关注：跑在终端里的开源编码 Agent，国内团队上手成本低，可以拿来和 Claude Code 类工具对比。

**vercel/ai**
[链接](https://github.com/vercel/ai)
为什么值得关注：TypeScript 生态里做 AI 应用的标准 SDK，Next.js 用户基本绕不开。

**eliza**
[链接](https://github.com/elizaOS/eliza)
为什么值得关注：开源 Agent 操作系统，生态活跃。适合研究多 Agent 编排的工程结构。
