## 🏢 官方产品 / 平台更新

### OpenAI 与 PwC 联手：用 AI Agent 重塑 CFO 办公室
[原文](https://openai.com/index/openai-pwc-finance-collaboration)  
**为什么关注**：不是概念合作，是普华永道直接将 OpenAI Agent 嵌入财务自动化流程——自动对账、预测、风控。这意味着 Agent 在严肃企业场景中开始“干活”了，利好做财务 SaaS 和 RPA 的团队。

### OpenAI 如何规模化交付低延迟语音 AI
[原文](https://openai.com/index/delivering-low-latency-voice-ai-at-scale)  
**为什么关注**：语音 AI 的产品化核心是延迟。OpenAI 重写了 WebRTC 栈，实现全球低延迟、无感轮换。做语音客服、语音助手的朋友可以当工程参考（虽然没开源细节，但方向明确）。

### OpenAI 高级账户安全（防钓鱼登录）
[原文](https://openai.com/index/advanced-account-security)  
**为什么关注**：企业客户上量后，安全是拦路虎。OpenAI 加了防钓鱼登录、强恢复机制——对做 AI 应用接入的企业来说，这降低了采购顾虑。

### GPT-5 “哥布林”异常行为复盘
[原文](https://openai.com/index/where-the-goblins-came-from)  
**为什么关注**：模型输出出现风格化“哥布林”现象，OpenAI 公开时间线、根因和修复。做 AI 产品的人要思考：模型不可控的“人格”会怎么影响用户体验，以及如何写 prompt 防御。

### AI 评估正在成为新的计算瓶颈
[原文](https://huggingface.co/blog/evaleval/eval-costs-bottleneck)  
**为什么关注**：Hugging Face 指出：评估（Eval）成本已经超过训练/推理成本。对落地团队来说，这是一个信号：别只追求模型能力，评估工程的效率也得重视。

### Granite 4.1 LLM：IBM 开源模型如何构建
[原文](https://huggingface.co/blog/ibm-granite/granite-4-1)  
**为什么关注**：IBM 坚持开源企业级模型，Granite 4.1 适合合规要求高的场景。关注点：它怎么处理数据、怎么微调，可能直接复用。

## 🚀 新产品 / 新工具

### Unity AI —— 游戏引擎里的 AI Agent
[Product Hunt](https://www.producthunt.com/products/unity)  
**为什么关注**：AI Agent 直接嵌入 Unity 工作流，做游戏开发的可以试试——NPC 决策、场景自动化，不用从零写代码。

### Openclick —— 把提示转成 macOS 自动点击
[Product Hunt](https://www.producthunt.com/products/openclick)  
**为什么关注**：低代码自动化。输入一段话，Agent 自动执行鼠标点击。适合测试、表单填写等重复操作，门槛极低。

### Airbyte Agents —— 生产级 Agent 的数据层
[Product Hunt](https://www.producthunt.com/products/airbyte-agents)  
**为什么关注**：做 Agent 最缺的是上下文数据。Airbyte 提供“数据上下文层”，让 Agent 能访问真实数据库——适合做客服、数据分析 Agent 的人。

### Tollecode —— 本地 AI 编程助手
[Product Hunt](https://www.producthunt.com/products/tollecode)  
**为什么关注**：把任务委托给本地 AI Agent，代码不离开机器。习惯 Copilot 但担心隐私的团队可以关注。

### Agentic API Grader —— 给 Agent 调用你的 API 打分
[Product Hunt](https://www.producthunt.com/products/saastr-ai-your-ai-powered-b2b-advisor)  
**为什么关注**：你的新客户可能是个 AI Agent，它会不会正确调用你的 API？这个工具帮 API 提供方评估 Agent 调用质量，产品经理和架构师值得一看。

### Blaze —— AI 日历，替你规划每天
[Product Hunt](https://www.producthunt.com/products/blaze-your-new-calendar)  
**为什么关注**：AI 日程助理的老赛道，但 Blaze 主打“直接帮你安排”，不是让你自己拖拽。喜欢自动化日程的朋友可以试试。

## 🛠️ 开源项目 / 工程落地

### Dify（140k+ ⭐）—— 生产级 Agent 工作流平台
[GitHub](https://github.com/langgenius/dify)  
**为什么关注**：国内最火的 Agent 平台之一，支持 RAG、工作流、模型接入，直接可部署。适合快速验证 Agent 业务，社区活跃。

### Hermes Agent（133k+ ⭐）—— 陪伴成长的 Agent 框架
[GitHub](https://github.com/NousResearch/hermes-agent)  
**为什么关注**：主打“随着你成长”，支持记忆、工具调用、多模态。重点是 Agent 能持续学习你的使用习惯，适合做个人助手。

### Prompt Optimizer（28k+ ⭐）—— 写更好的 prompt
[GitHub](https://github.com/linshenkx/prompt-optimizer)  
**为什么关注**：AI prompt 越来越重要，这个工具自动优化你的 prompt，输出更稳定。开发者和非技术用户都能用。

### Open Design（25k+ ⭐）—— 开源版 Claude Design
[GitHub](https://github.com/nexu-io/open-design)  
**为什么关注**：本地优先、开源的 UI 生成工具，内置 71 套设计系统。前端工程师做原型、产品经理出高保真草图的利器。

### Activepieces（22k+ ⭐）—— 400+ MCP 服务器集成
[GitHub](https://github.com/activepieces/activepieces)  
**为什么关注**：AI 工作流自动化平台，重点是对接了 400 多个 MCP（模型上下文协议）服务器。用 Agent 串联各种工具的朋友必看。

### Screenpipe（18k+ ⭐）—— 记录你屏幕和麦克风的 Agent
[GitHub](https://github.com/screenpipe/screenpipe)  
**为什么关注**：24/7 本地录制屏幕+麦克风，Agent 根据你的行为自动工作。隐私友好（本地运行），适合做“记忆助手”或自动化测试。
