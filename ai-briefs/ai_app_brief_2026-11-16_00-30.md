## 官方产品 / 平台更新

**ChatGPT Wallet 发布**
[链接](https://openai.com/index/introducing-chatgpt-wallet)

值得关注：Agent 从“帮你查”走到“帮你付”，支付授权和风控会是落地关键。

**Shield 用 OpenAI 接手遗留门户的重复操作**
[链接](https://openai.com/business/customer-stories/shield)

值得关注：遗留系统没人想碰，这类“代操作”是最容易算出 ROI 的场景。

**Amplitude 用 OpenAI 把产品改进压到 1–2 天**
[链接](https://openai.com/business/customer-stories/amplitude)
产品 agent Wave 负责找该做什么，再配合编码工具把改动发出去。
值得关注：从发现问题到上线串成一条链，是团队级 Agent 的样板。

**Gondola 用 Codex 把主工程师产出提了 50%**
[链接](https://openai.com/business/customer-stories/gondola)
值得关注：小团队用编码 agent 放大个人产能的真实案例，比 benchmark 更有参考价值。

**用 SimReady 资产搭机器人抓取仿真**
[链接](https://huggingface.co/blog/nvidia/simready-assets-robot-pick-and-place)
值得关注：机器人落地先要在仿真里跑通，现成资产能省掉大量建模时间。

**XYBench：帮你看清问题背后的问题**
[链接](https://huggingface.co/blog/allenai/xybench)
值得关注：评测开始关注“问对问题”，这对做 Agent 任务拆解的人有直接启发。

## 开源项目 / 工程落地

**NousResearch/hermes-agent**（26.3 万 stars）
[链接](https://github.com/NousResearch/hermes-agent)
值得关注：star 量级说明社区关注度极高，适合作为 agent 框架选型的候选。

**CherryHQ/cherry-studio**（5.3 万 stars）
[链接](https://github.com/CherryHQ/cherry-studio)
把模型、agent 和日常效率工具放进一个工作台。
值得关注：桌面端 AI 工作台里比较成熟的一个，适合个人和小团队直接用。

**sgl-project/sglang**（3.9 万 stars）
[链接](https://github.com/sgl-project/sglang)

值得关注：自部署推理绕不开的选项，多模态场景可以重点看。

**activepieces/activepieces**（2.5 万 stars）
[链接](https://github.com/activepieces/activepieces)
AI agent、MCP 和工作流自动化，带约 400 个 MCP server。
值得关注：想把 Agent 接进现有业务流程，这类自动化平台上手最快。

**ccch1mneyyy/dsh-Go**（2.3 万 stars）
[链接](https://github.com/ccch1mneyyy/dsh-Go)

值得关注：移动端跑 agent 的思路，对“随身 AI 助手”这个方向有参考价值。

**omnigent-ai/omnigent**（1.1 万 stars）
[链接](https://github.com/omnigent-ai/omnigent)
开源 agent 框架兼 meta-harness，可编排 Claude Code、Codex、Cursor 等并随时换 harness。
值得关注：不想被单一 agent 工具绑死的团队，可以看看它的抽象方式。
