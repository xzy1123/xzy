## 🛠️ 新产品 / 新工具

[Product Hunt](https://www.producthunt.com/products/upsolve-ai)  
强调“有监管、可追溯、值得信任”。适合企业内部需要对接复杂数据源的场景。  

**API to MCP** — 把任意 API 变成 MCP 服务器  
[Product Hunt](https://www.producthunt.com/products/api-to-mcp)  
MCP 是 Agent 与外部服务交互的协议。这个工具让你一分钟将现有 API 包装成 Agent 可调用的格式。  

**Zernio WhatsApp API** — 统一消息、通话、AI Agent  
[Product Hunt](https://www.producthunt.com/products/zernio)  
一套 API 搞定 WhatsApp 消息、语音通话和 AI Agent。做海外客服的团队可以试试。  

**Firecrawl Research Index** — 给 Agent 用的 AI/ML 研究索引  
[Product Hunt](https://www.producthunt.com/products/extract-by-firecrawl)  
让 Agent 能直接搜索和提取前沿论文信息。适合需要自动跟踪研究动态的团队。  

**Midjourney Scanner** — 60 秒超声波全身扫描  
[Product Hunt](https://www.producthunt.com/products/midjourney)  
注意：这是硬件设备，中标“AI 应用观察”方向。但把 AI 图像生成技术用到医疗扫描，脑洞很大。  

**MeshPilot** — 终端、任务和 Agent 的 AI 工作台  
[Product Hunt](https://www.producthunt.com/products/meshpilot)  
把命令行、自动化任务和 AI Agent 集成到一个界面。适合喜欢在终端里折腾的工程师。

## 🔧 开源项目 / 工程落地

**Langfuse** — AI 工程平台  
[GitHub 29376⭐](https://github.com/langfuse/langfuse)  
LLM 评估、可观测性、指标、提示管理、测试集。配合 OpenTelemetry 使用，是生产中必备的监控套件。  

**Vercel AI SDK** — TypeScript 的 AI 工具包  
[GitHub 24983⭐](https://github.com/vercel/ai)  
Next.js 官方出品，帮你快速构建 AI 应用。支持流式、工具调用、多模态。前端工程师的保姆级工具。  

**Outlines** — 结构化输出库  
[GitHub 13977⭐](https://github.com/dottxt-ai/outlines)  
强制 LLM 生成 JSON、代码等结构化内容。写 Agent 时最烦“回复乱七八糟”，用它解决。  

**Vibe-Trading** — 你的个人交易 Agent  
[GitHub 12632⭐](https://github.com/HKUDS/Vibe-Trading)  
量化交易也可以 Vibe Coding？开源项目，可能不适合实盘，但用来学 AI 交易策略很有趣。  

**Bifrost** — 企业 AI 网关，号称比 LiteLLM 快 50 倍  
[GitHub 5901⭐](https://github.com/maximhq/bifrost)  
负载均衡、集群模式、护栏、支持 1000+ 模型，延迟低于 100 μs。高并发场景的替代方案。  

**Omnigent** — 开源 Agent 编排框架  
[GitHub 3938⭐](https://github.com/omnigent-ai/omnigent)  
统一调度 Claude Code、Codex、Cursor 等 Agent，还能自定义。适合需要统一管控多个 Agent 的团队。
