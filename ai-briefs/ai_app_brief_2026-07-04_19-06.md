**Glaze by Raycast**

**Tamamon**

**Vox**  
[🔗 Product Hunt](https://www.producthunt.com/products/vox-5)

## 🧰 开源项目 / 工程落地

**Dify（langgenius/dify）** ⭐ 147,604  
[🔗 GitHub](https://github.com/langgenius/dify)  
**为什么值得关注**：生产级 Agent 工作流平台，适合不想从零搭背景下的企业级部署。今天依然在更新，生态成熟，中文社区活跃，落地首选之一。

**Open Design（nexu-io）** ⭐ 74,824  
[🔗 GitHub](https://github.com/nexu-io/open-design)  
**为什么值得关注**：开源版的 Claude Design 替代品，本地优先桌面应用，让你的 coding agent 变成设计师。适合前端开发者和 UI 设计师的工作流融合。

**Cherry Studio（CherryHQ）** ⭐ 48,137  
[🔗 GitHub](https://github.com/CherryHQ/cherry-studio)  
**为什么值得关注**：智能聊天 + 自主 Agent + 300+ 助手，统一接入主流大模型。适合想要一站式生产力工具的用户、以及需要多模型切换测试的团队。

**OpenVINO（openvinotoolkit）** ⭐ 10,466  
[🔗 GitHub](https://github.com/openvinotoolkit/openvino)  
**为什么值得关注**：Intel 的推理优化工具包，适合把模型部署到 CPU 或边缘设备。如果你的 AI 应用需要低延迟、低成本推理，OpenVINO 是实战利器。

**JCode（1jehuang）** ⭐ 8,124  
[🔗 GitHub](https://github.com/1jehuang/jcode)  
**为什么值得关注**：Coding Agent 的“缰绳”框架，让你更好地控制 Agent 行为。适合想要在现有 Agent 基础上做定制、添加安全边界或交互逻辑的团队。

**gptme（gptme）** ⭐ 4,352  
[🔗 GitHub](https://github.com/gptme/gptme)  
**为什么值得关注**：纯终端 Agent，能写代码、浏览网页、用本地工具。适合偏好命令行、或者想构建自动化流水线（如 CI/CD Agent）的开发者。
