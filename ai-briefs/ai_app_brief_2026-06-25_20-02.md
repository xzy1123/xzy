## 官方产品 / 平台更新

### Agent如何改变工作
[OpenAI 官方文章](https://openai.com/index/how-agents-are-transforming-work)  
**为什么值得关注**：OpenAI 用实际研究演示了 AI Agent 从单次问答转向多步骤、长时长任务。这对所有做自动化工作流、客服、代码生成的团队都是信号——Agent 的“续航”和“复杂度”正在成倍提升，产品形态可以从“问答机器人”升级为“数字员工”。

### OpenAI 与 Broadcom 推出推理芯片 Jalapeño
[OpenAI 官方公告](https://openai.com/index/openai-broadcom-jalapeno-inference-chip)  
**为什么值得关注**：这是一颗专为大模型推理设计的芯片，目标是提升推理效率、降低延迟和成本。对开发者来说，意味着未来调用 GPT 系列会更便宜、更快，应用层的成本压力降低，更多实时场景（如语音、视频分析）变得可行。

### GPT-5 Pro 帮助免疫学家解决三年未解之谜
[OpenAI 案例](https://openai.com/index/gpt-5-immunology-mystery)  
**为什么值得关注**：GPT-5 Pro 在免疫学研究中找到了 T 细胞行为的规律，破解了长达三年的谜题。这不是实验室的玩具，而是真正被科学家当作“分析助手”用在了科研一线。方向很明确：垂直领域的 AI 应用（生物医药、材料、法律）将更快从概念走向生产。

### NVIDIA NeMo AutoModel 加速 Transformer 微调
[Hugging Face 博客](https://huggingface.co/blog/nvidia/accelerating-fine-tuning-nvidia-nemo-automodel)  
**为什么值得关注**：如果你们团队经常做模型微调，这个工具能省不少时间。NVIDIA 将其自动化，减少了手动调参和流程编排的功夫。适合企业内部做垂直模型的小规模快速迭代。

### FFASR 排行榜：真实场景下的语音识别基准
[Hugging Face 博客](https://huggingface.co/blog/ffasr-leaderboard)  
**为什么值得关注**：以前 ASR 评测只看学术数据集，这个排行榜重点关注真实录音（噪声、口音、多说话人）。做语音交互产品的团队需要关注，它帮你挑出真正能落地的模型，而不是“刷榜”选手。

## 新产品 / 新工具

### Heron —— Agent 的“Wireshark”
[Product Hunt](https://www.producthunt.com/products/heron)  
**为什么值得关注**：Agent 跑起来后你怎么知道它在干嘛？Heron 用 eBPF 做被动可观测性，不侵入代码就能监控 Agent 行为。做 Agent 自动化工作流的团队，调试和监控是刚需，这个工具正好补位。

### BrowserAct —— 给 Agent 用的浏览器自动化
[Product Hunt](https://www.producthunt.com/products/browseract)  
**为什么值得关注**：让 AI Agent 像人一样操作网页（点按钮、填表单），而不是只靠 API。对做 RPA、爬虫或浏览器外挂的团队来说，这是 Agent 落地的关键能力。

### Genspark Design —— AI 生成 UI 原型、视频和海报
[Product Hunt](https://www.producthunt.com/products/genspark-design)  
**为什么值得关注**：从文本直接生成可交互原型和视频，设计师和产品经理的工作流会变。适合快速产出演示、A/B 测试素材。

### Sidegent —— 边做边学构建 AI Agent
[Product Hunt](https://www.producthunt.com/products/sidegent)  
**为什么值得关注**：不是读教程，而是直接上手搭建 Agent，适合开发者快速上手 Agent 开发，降低学习门槛。

## 开源项目 / 工程落地

### infiniflow/ragflow ⭐ 83,610
[GitHub](https://github.com/infiniflow/ragflow)  
**为什么值得关注**：RAG 引擎 + Agent 能力，支持文档问答、知识库检索、任务编排。提供了产品级的 UI 和 API，适合企业直接拿来当内部知识库或客服系统。

### safishamsi/graphify ⭐ 71,866
[GitHub](https://github.com/safishamsi/graphify)  
**为什么值得关注**：一个 AI 编程助手 Skill（兼容 Claude Code、Cursor 等），能把任意代码文件夹、SQL、脚本等变成可交互的知识图谱。对代码审查、项目 onboarding 很有用。

### BerriAI/litellm ⭐ 51,513
[GitHub](https://github.com/BerriAI/litellm)  
**为什么值得关注**：统一的 API 网关，支持 100+ LLM，自动负载均衡、成本追踪、安全过滤。做多模型集成或切模型的后端团队几乎是必用。

### langfuse/langfuse ⭐ 29,758
[GitHub](https://github.com/langfuse/langfuse)  
**为什么值得关注**：开源 AI 工程平台，覆盖 prompt 管理、评估、可观测性。适合需要规范 LLM 应用开发和迭代的团队，可视化和调试都很方便。
