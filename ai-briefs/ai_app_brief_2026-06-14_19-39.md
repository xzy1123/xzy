## 新产品 / 新工具

**Slashy —— 帮你回邮件的 AI 助手**  
[Slashy](https://www.producthunt.com/products/slashy-3)  
为什么值得关注：不需要学新工具，直接接管你的邮箱自动回复。适合每天被邮件淹没的职场人，落地门槛低。

**Memoriq —— 给 ChatGPT/Claude 等配一个私有记忆库**  
[Memoriq](https://www.producthunt.com/products/memoriq)  
为什么值得关注：跨模型共享记忆，数据存在本地，不泄漏。适合频繁切换 AI 工具但希望对话连贯的用户，也是“记忆层”产品的实用参考。

**Folio —— Claude 版 PowerPoint（增强版）**  
[Folio](https://www.producthunt.com/products/folio-ai)  
为什么值得关注：用 Claude 生成 PPT，效果比 chat 直接输出强很多。做汇报材料的人可以试试，减少重复排版。

**Conan —— Claude Code 的 Mac 原生控制台**  
[Conan](https://www.producthunt.com/products/conan)  
为什么值得关注：给 Claude Code 配了一个 Mac 桌面面板，可以可视化操作、管理会话。适合喜欢在终端用 AI 但又想要图形界面的开发者。

**Prometheus by Firecrawl —— 网页数据抓取 Agent**  
[Prometheus by Firecrawl](https://www.producthunt.com/products/extract-by-firecrawl)  
为什么值得关注：这不是传统爬虫，是“前置部署”Agent，能理解网页结构、自动提取数据。做数据采集、竞品分析的工程团队重点关注。

**Kimi K2.7 Code —— Kimi 最强代码模型上线**  
[Kimi K2.7 Code](https://www.producthunt.com/products/kimi-ai-assistant)  
为什么值得关注：中文场景下最擅长写代码的 Kimi 版本，支持复杂项目生成。国内开发者可以对比一下和 Cursor / Claude 的体验。

## 开源项目 / 工程落地

**NousResearch/hermes-agent —— 会成长的 Agent 框架**  
[hermes-agent](https://github.com/NousResearch/hermes-agent) ⭐ 193k  
为什么值得关注：轻量级、自学习，Agent 能根据你的使用习惯调整行为。适合想做长期运行的自定义助手。

**huggingface/transformers —— 多模态模型全家桶**  
[transformers](https://github.com/huggingface/transformers) ⭐ 161k  
为什么值得关注：老牌框架持续更新，想快速调用文本/语音/视觉模型，用它就对了。落地首选。

**nexu-io/open-design —— 本地优先的 Claude Design 替代品**  
[open-design](https://github.com/nexu-io/open-design) ⭐ 64k  
为什么值得关注：支持259+技能、142+设计系统，本地运行，原生桌面应用。设计师和开发者协作时用，避免在线工具数据泄漏。

**HKUDS/nanobot —— 轻量开源 Agent，连接工具/聊天/工作流**  
[nanobot](https://github.com/HKUDS/nanobot) ⭐ 44k  
为什么值得关注：小而美，支持插件体系，适合自建内部自动化工具体系。

**esengine/DeepSeek-Reasonix —— 终端里跑 DeepSeek 原生 Agent**  
[DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix) ⭐ 21k  
为什么值得关注：专为 DeepSeek 优化的编码 Agent，前缀缓存稳定，可以一直挂着。用 DeepSeek 做开发的同学直接部署。

**EKKOLearnAI/hermes-studio —— Hermes Agent 的 Web 管理面板**  
[hermes-studio](https://github.com/EKKOLearnAI/hermes-studio) ⭐ 7.8k  
为什么值得关注：配合 hermes-agent 使用，提供多平台聊天、会话管理、定时任务、用量分析。适合团队部署 Agent 后需要可视化维护。
