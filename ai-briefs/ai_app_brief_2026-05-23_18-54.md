## 开源项目 / 工程落地

### langflow-ai/langflow —— 可视化构建 AI Agent 工作流  
[GitHub: langflow-ai/langflow](https://github.com/langflow-ai/langflow) ⭐148k  
**为什么值得关注**：拖拽式搭建 AI 管道，无需写代码。适合快速原型验证，也适合非技术人员参与流程设计。更新频繁，生态活跃。

### langgenius/dify —— 生产级 Agentic 工作流平台  
[GitHub: langgenius/dify](https://github.com/langgenius/dify) ⭐142k  
**为什么值得关注**：比 Langflow 更偏向生产部署，自带 RAG、工具调用、日志监控。如果你要把 Agent 做成产品，Dify 是目前最成熟的开源选择之一。

### nexu-io/open-design —— 本地优先的开源 Claude Design 替代  
[GitHub: nexu-io/open-design](https://github.com/nexu-io/open-design) ⭐50k  
**为什么值得关注**：19 种技能 + 71 套品牌设计系统，可生成网页、桌面、移动端原型。适合设计师和前端团队用来快速出图，减少设计稿返工。

### miurla/morphic —— AI 搜索 + 生成式 UI  
[GitHub: miurla/morphic](https://github.com/miurla/morphic) ⭐8.9k  
**为什么值得关注**：搜索结果的展示不再只是链接，而是 AI 生成的动态界面。如果你在做企业内部知识库或客服系统，这个交互方式值得试。

### EKKOLearnAI/hermes-web-ui —— Hermes Agent 的 Web 仪表盘  
[GitHub: EKKOLearnAI/hermes-web-ui](https://github.com/EKKOLearnAI/hermes-web-ui) ⭐5.8k  
**为什么值得关注**：多平台 AI 聊天、会话管理、定时任务、用量分析都集成在一个 Web 界面。适合团队需要统一管理多个 Agent 的场景。

### modu-ai/moai-adk —— 面向 Claude Code 的 SPEC-First 开发工具包  
[GitHub: modu-ai/moai-adk](https://github.com/modu-ai/moai-adk) ⭐1k  
**为什么值得关注**：把“先写 spec 再写代码”的流程固化到 Agent 开发中，支持 TDD/DDD。适合追求高质量代码、减少 AI 幻觉的团队。
