## 开源项目 / 工程落地

### hermes-agent —— 随你成长的 Agent
链接：https://github.com/NousResearch/hermes-agent

**为什么值得关注**：一个能长期维护、随使用习惯进化的 Agent 是目前少有的方向，适合想自建个人助手的技术同学关注。

### open-design —— 开源版 Claude Design
链接：https://github.com/nexu-io/open-design

本地优先的桌面应用，让编码 Agent 变身设计引擎，能生成原型和落地页。

**为什么值得关注**：设计的核心瓶颈是“从想法到原型的距离”。如果编码 Agent 能直接产出设计稿，小团队可以省掉一个设计环节。

### OpenHands —— AI 驱动的开发平台
链接：https://github.com/OpenHands/OpenHands

全流程 AI 开发助手，帮你写代码、跑命令、管理项目。

**为什么值得关注**：8 万+ star 的头部开源项目，社区活跃度说明一切。想搭自己的 AI 编程环境，从这里开始最稳。

### headroom —— 给 LLM 瘦身：减少 20%-95% token
链接：https://github.com/headroomlabs-ai/headroom

在 token 进入 LLM 前压缩工具输出、日志、文件和 RAG 片段。编码 Agent 省 20%，JS 场景省 60-95%。

**为什么值得关注**：token 就是钱。对高频调用 API 的团队，这个项目可以直接拉低账单，属于“接入即省钱”的工具。

### Langfuse —— 开源 AI 工程平台
链接：https://github.com/langfuse/langfuse

提供 LLM 评测、可观测性、指标、提示词管理、数据集，集成 OpenTelemetry。

**为什么值得关注**：生产环境的 LLM 应用离不开“可观测和评测”。Langfuse 把整套体系开源了，是搭建 AI 应用基础设施的省力选项。

### Haystack —— 生产级 LLM 编排框架
链接：https://github.com/deepset-ai/haystack

开源 AI 编排框架，用于构建上下文工程化、可上生产的 LLM 应用。

**为什么值得关注**：轻量方案很多，但“能上生产”是另一回事。Haystack 提供了模块化管道和 Agent 设计，适合对稳定性有要求的团队。
