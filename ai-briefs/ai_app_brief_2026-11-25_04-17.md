## 开源项目 / 工程落地

**langchain-ai/langchain**
[链接](https://github.com/langchain-ai/langchain)
Agent 工程平台，近 15 万星。值得关注的是它仍是很多团队搭 Agent 的默认起点，生态和文档最全。

**paperclipai/paperclip**
[链接](https://github.com/paperclipai/paperclip)
开源的工作场景 Agent 管理应用。值得关注的是“管理 Agent”本身成了独立品类，团队里 Agent 一多就需要这类工具。

**headroomlabs-ai/headroom**
[链接](https://github.com/headroomlabs-ai/headroom)
在内容进 LLM 前压缩工具输出、日志、文件和 RAG 片段，编码 Agent 省 20% token，JS 场景省 60-95%。值得关注的是省钱直接可量化，成本敏感的团队值得试。

**vercel/ai**
[链接](https://github.com/vercel/ai)
TypeScript 的 AI 工具包，Next.js 团队出品。值得关注的是前端栈做 AI 应用的事实标准，上手快。

**activepieces/activepieces**
[链接](https://github.com/activepieces/activepieces)
AI 工作流自动化，带约 400 个 MCP 服务器。值得关注的是 MCP 生态在开源自动化工具里落地，接内部系统会省不少事。

**elizaOS/eliza**
[链接](https://github.com/elizaOS/eliza)
开源 Agent 操作系统。值得关注的是“Agent OS”这个方向还在被认真做，想了解 Agent 长期形态可以看。
