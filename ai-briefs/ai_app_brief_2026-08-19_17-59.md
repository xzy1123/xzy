## 📦 开源项目 / 工程落地

### claude-mem —— 给 Agent 装上长期记忆
🔗 [github.com/thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) ⭐ 91,208

Agent 会话结束后，自动把全过程压缩、存储，下一次会话自动注入上下文。

**为什么值得关注：** 目前 Agent 落地最大的痛点之一就是“一聊就忘”。这个项目让 AI 跨会话记得你的项目背景和偏好，等于给 Agent 开了“存档”功能。91k star 说明需求非常真实。

---

### RAGFlow —— 开源 RAG 引擎标杆
🔗 [github.com/infiniflow/ragflow](https://github.com/infiniflow/ragflow) ⭐ 88,813

把 RAG 和 Agent 能力结合，做企业级知识库问答引擎。

**为什么值得关注：** 做知识库问答，RAGFlow 基本是绕不开的参考实现。大厂背书、社区活跃，适合作为企业知识库底座的起点。

### DeepSeek-Reasonix —— 终端里的 DeepSeek 编程 Agent

**为什么值得关注：** 国内团队用 DeepSeek 的话，这是 Claude Code 的一个实用替代品。特别适合不想买海外信用卡、又想用终端编码 Agent 的开发者。

### Langfuse —— 开源 LLM 可观测性平台
🔗 [github.com/langfuse/langfuse](https://github.com/langfuse/langfuse) ⭐ 33,373

LLM 评估、可观测性、指标监控、提示词管理、数据集管理，一个平台搞定。

**为什么值得关注：** 应用上线后不能“盲跑”。生产环境追踪、评估、调优，Langfuse 是目前开源生态里比较全面的选择。
