## 新产品

**ChikitAI** – 医疗分诊与护理自动化 Agent
[链接](https://www.producthunt.com/products/chikitai)  
面向医疗场景：自动分析症状、分流、调度护理资源。国内类似方向可以关注合规落地的差异。

**Manta AI** – 自主 Web 应用测试 Agent
[链接](https://www.producthunt.com/products/manta-ai)  
你描述测试场景，它自动跑 UI 交互、截图、报告 bug。适合 QA 团队从“写脚本”升级到“提需求”。

**Cito** – 面向 Agent 的混合学术搜索（2.36 亿论文）
[链接](https://www.producthunt.com/products/cito)  
专门为 Agent 设计的论文检索 API，支持语义+关键词混合。做知识库工具的团队可以看看它的索引策略。

**River** – 能演示和签约的 AI 销售代表
[链接](https://www.producthunt.com/products/river-9)  
自动给客户做 demo、回答技术问题、甚至直接走签约流程。B2B 销售流程的“最后一公里”自动化正在变现实。

**Amami** – 内嵌在 AI 助手里的分析
[链接](https://www.producthunt.com/products/amami)  
你想在跟 AI 对话时直接看数据看板？Amami 把分析功能塞进 Chat。不跳转、不切工具。

**Kit For AI** – Agent 的记忆层
[链接](https://www.producthunt.com/products/kit-for-ai)  
让 Agent 记住你是谁、你喜欢什么、上次聊到哪。挂载在任意 LLM 之上，解决“AI 没有长期记忆”这个经典痛点。

## 开源项目

**Dify** ⭐149k – 生产级 Agent 工作流平台
[链接](https://github.com/langgenius/dify)  
持续更新，中文社区最爱。把 RAG、Agent、工作流拖拽起来，适合快速原型和内部工具。

**RAGFlow** ⭐85k – 领先的 RAG + Agent 引擎
[链接](https://github.com/infiniflow/ragflow)  
把检索增强和 Agent 能力合二为一。中文文档完善，适合做知识库问答和文档处理的团队。

**open-design** ⭐79k – 开源版 Claude Design
[链接](https://github.com/nexu-io/open-design)  
让编码 Agent 也能干设计：出原型图、landing page。前端设计师和全栈开发的新玩具。

**cherry-studio** ⭐49k – AI 生产力工作室
[链接](https://github.com/CherryHQ/cherry-studio)  
集成了 300+ 助手、智能对话、自主 Agent。一次接入即可调度主流 LLM，适合个人/小团队做工具集合。

**DeepSeek-Reasonix** ⭐27k – 为 DeepSeek 打造的终端编码 Agent
[链接](https://github.com/esengine/DeepSeek-Reasonix)  
围绕 prefix-cache 稳定性优化，可以一直挂着跑。适合重度使用 DeepSeek 的开发者。

**DB-GPT** ⭐19k – 开源 Agent 数据助手
[链接](https://github.com/eosphoros-ai/DB-GPT)  
让 AI 直接操纵数据库做分析、查数据、写报表。数据团队的“SQL 杀手”。
