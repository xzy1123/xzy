## 新产品 / 新工具

**Alsona**
[链接](https://www.producthunt.com/products/alsona)
用 AI Agent 把购买信号转成已预约的销售电话。值得关注的是它盯的是“信号到成单”这段，销售团队可以对照自己的线索流程看有没有可替代环节。

**Rodeo**
[链接](https://www.producthunt.com/products/rodeo-7)
Notion 替代品，免费版就带 AI 会议记录。对预算敏感的小团队来说，等于把文档和会议纪要合到一个工具里。

**SideKick By Open**
[链接](https://www.producthunt.com/products/open-for-sales)
自称“Claude，但是针对你的产品”。值得关注的是这类“产品内 AI 助手”正在变成标准配置，做 SaaS 的可以想想自己的产品里该放什么。

**Latch.ai**
[链接](https://www.producthunt.com/products/latch-ai-2)
不用写 prompt 就能自动化复杂会计工作。财务这类规则多、重复多的场景，是 AI 落地比较实在的方向。

**Lottie AI**
[链接](https://www.producthunt.com/products/lottiefiles)
用文字生成可编辑的矢量动画。做运营物料、产品动效的可以试试，省掉一部分找素材和改动画的时间。

**Seldon**
[链接](https://www.producthunt.com/products/seldon)
行为级 QA Agent，像真实用户一样使用你的产品。值得关注的是测试从“点按钮”往“模拟人”走，适合有复杂交互流程的产品。

## 开源项目 / 工程落地

**NousResearch/hermes-agent**
[链接](https://github.com/NousResearch/hermes-agent)
“跟着你一起成长的 Agent”。star 数很高，适合想自己搭 Agent 底座、又不想从零写框架的团队先跑一遍。

**paperclipai/paperclip**
[链接](https://github.com/paperclipai/paperclip)
开源的工作用 Agent 管理应用。团队里 Agent 越接越多时，统一管理会变成真问题，这类工具值得提前看。

**BerriAI/litellm**
[链接](https://github.com/BerriAI/litellm)
AI Gateway，Rust 核心加 Python SDK，一套接口调 100+ LLM，带成本追踪和护栏。多模型混用的团队基本绕不开这类网关，落地价值很直接。

**elizaOS/eliza**
[链接](https://github.com/elizaOS/eliza)
开源 Agent 操作系统。适合关注 Agent 运行环境、多 Agent 协作的人跟进。

**lidge-jun/opencodex**
[链接](https://github.com/lidge-jun/opencodex)
给 OpenAI Codex 和 Claude Code 做通用 provider 代理，可以接 Claude、Gemini、Grok、DeepSeek、Ollama 等。想换模型又不想改工作流的开发者可以看。

**rddmwmddr/android-ad-cleaner**
[链接](https://github.com/rddmwmddr/android-ad-cleaner)
关掉国产安卓系统里的广告、热搜和营销推送，不 root、可还原，支持 AI 智能体一键执行。中文场景、需求明确，属于“小工具解决真麻烦”的类型。
