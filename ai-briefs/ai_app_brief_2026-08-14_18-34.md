## 开源项目 / 工程落地

### 🤗 Transformers
[GitHub - 164k stars](https://github.com/huggingface/transformers)

**为什么值得关注：** 多模态模型的事实标准框架，文本、视觉、音频通吃。昨天还在更新，社区活跃度极高，做模型推理和服务化绕不开它。

### Dify
[GitHub - 152k stars](https://github.com/langgenius/dify)

**为什么值得关注：** 一站式做 Agentic 工作流和 RAG 管道，支持云、VPC 和私有化部署。中文团队出品，文档友好，是目前企业搭 AI 应用最顺手的开源方案之一。

### RAGFlow
[GitHub - 88k stars](https://github.com/infiniflow/ragflow)

**为什么值得关注：** 开源 RAG 引擎 + Agent 能力结合，专注把"检索增强生成"做到好用。如果你的场景是文档问答、知识库对话，这个项目几乎是必看。

### DeepSeek-Reasonix
[GitHub - 35k stars](https://github.com/esengine/DeepSeek-Reasonix)

**为什么值得关注：** DeepSeek 原生的终端编程 Agent，主打 prefix-cache 稳定，能一直挂着跑。想用 DeepSeek 做编程助手、又想省成本的开发者可以试试。

### Qwen Code
[GitHub - 27k stars](https://github.com/QwenLM/qwen-code)

**为什么值得关注：** 阿里开源终端编程 Agent。在 DeepSeek、Claude Code 之外多一个选择，中文支持友好，和国内模型生态结合更紧密。

### ElizaOS
[GitHub - 19k stars](https://github.com/elizaOS/eliza)

**为什么值得关注：** 自称"开源的 Agent 操作系统"，想做 Agent 的基础设施层。关注多 Agent 编排的可以看这个项目。
