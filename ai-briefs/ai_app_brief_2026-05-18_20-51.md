### Databricks 将 GPT-5.5 引入企业 Agent 工作流
[链接](https://openai.com/index/databricks)

**为什么值得关注**：GPT-5.5 在 OfficeQA Pro 标杆上达到新 SOTA，Databricks 将其用于自动化的企业 Agent 流程（如报表生成、客户分析）。说明最先进的模型正被直接包装成业务工具，降低企业集成门槛。

### 数据科学团队如何使用 Codex
[链接](https://openai.com/academy/codex-for-work/how-data-science-teams-use-codex)
**为什么值得关注**：Codex 面向数据科学场景，能自动生成根因分析、KPI 备忘录、仪表盘说明等。对团队提效是实实在在的——写报告的时间可以砍半。

### 销售团队如何使用 Codex
[链接](https://openai.com/academy/codex-for-work/how-sales-teams-use-codex)
**为什么值得关注**：销售团队用 Codex 生成管道简报、会议准备包、预测回顾、客户计划等。相当于每个销售配了一个运营助理，对 CRM 流程自动化很有启发。

### IBM 开源 Granite Embedding Multilingual R2：32K 上下文，<100M 参数
[链接](https://huggingface.co/blog/ibm-granite/granite-embedding-multilingual-r2)

**为什么值得关注**：多语言嵌入模型，支持 32K 上下文，参数小于 100M 但检索质量逼近顶尖。Apache 2.0 开源，对构建知识库和搜索增强（RAG）的团队来说，这是一个高性能、轻量级的选择，可以本地部署。

### 连续 batching 中的异步机制
[链接](https://huggingface.co/blog/continuous_async)

**为什么值得关注**：大模型推理部署的经典“连续批处理”技术引入异步模式，可提升吞吐量、降低首 token 延迟。跑过推理服务的同学都懂，这直接关系成本和服务质量。

[链接](https://www.producthunt.com/products/landinghero-ai-2)

### Shadow：AI 控制电脑屏幕和语音，自定义自动化
[链接](https://www.producthunt.com/products/shadow-4)

**为什么值得关注**：能接管屏幕和语音的 AI Agent，用户可设置自定义自动化流程。类似 RPA 但更智能，适合个人办公或企业流程（比如自动填写表单、操作软件）。

### Searchad.ai：聊天式运营 Apple Search Ads
[链接](https://www.producthunt.com/products/searchad-ai)

**为什么值得关注**：用对话的方式管理苹果搜索广告，降低运营门槛。做得好的话，能让不熟悉广告系统的团队直接上手。

### Draft：把 AI 对话抓取到知识库
[链接](https://www.producthunt.com/products/draft-12)

**为什么值得关注**：自动保存 AI 聊天记录并结构化到知识库，解决“问完就忘”的痛点。对知识管理团队很实用，尤其适合内部 FAQ 和项目复盘。

### Agentspan：开源的可持久化 AI Agent 运行时
[链接](https://www.producthunt.com/products/agentspan)

**为什么值得关注**：开源框架，专为“持久化 Agent”设计——Agent 可以长时间运行、有状态、支持重试。适合需要后台持续监控、自动响应的场景（如客服、数据 ETL）。

### Triggered Agents by Adaptive：业务事件触发的 AI Agent
[链接](https://www.producthunt.com/products/triggered-agents-by-adaptive)

**为什么值得关注**：让 AI Agent 根据 CRM、ERP 等业务事件自动触发执行，比如客户下单后自动生成跟进邮件。这是 AI 融入现有工作流的典型方式，落地性强。

## 开源项目 / 工程落地

### Unsloth Studio：本地训练运行开源大模型
[GitHub](https://github.com/unslothai/unsloth) ⭐ 64.5k

**为什么值得关注**：提供 Web UI 在本地训练和运行 Gemma 4、Qwen3.6、DeepSeek、gpt-oss 等模型。对需要微调私有数据的团队来说，省去了写代码、配环境的麻烦，直接图形化操作。

### Open Design：本地优先的 Claude Design 开源替代
[GitHub](https://github.com/nexu-io/open-design) ⭐ 44.5k

**为什么值得关注**：开源、本地的设计生成工具，支持 19 种技能、71 套企业级设计系统，可以生成 Web/桌面/移动端 UI。前端团队做原型、内部工具时，不用依赖第三方服务。

### CUA：计算机使用 Agent 的开源基础设施
[GitHub](https://github.com/trycua/cua) ⭐ 16.9k

**为什么值得关注**：提供沙箱、SDK、基准测试，让 AI Agent 能控制完整桌面环境（操作 GUI、运行测试）。对想做浏览器自动化、软件测试、数据抓取的团队来说，现成的框架可以直接用。

### Tencent WeKnora：文档→RAG + 推理 Agent + Wiki 开源平台
[GitHub](https://github.com/Tencent/WeKnora) ⭐ 15.2k

**为什么值得关注**：腾讯开源的知识平台，一段流程走完：原始文档 -> 可查询的 RAG 知识库 -> 自主推理 Agent -> 自动维护的 Wiki。智能客服、内部知识库搭建直接套用。

### OpenVINO：优化和部署 AI 推理的开源工具包
[GitHub](https://github.com/openvinotoolkit/openvino) ⭐ 10.3k

**为什么值得关注**：英特尔的经典推理优化工具，支持多种硬件加速。在边缘端、服务器端部署模型时，能提升性能、降低成本。最近更新值得关注。

### Read Frog：开源沉浸式翻译工具
[GitHub](https://github.com/mengxi-ream/read-frog) ⭐ 6.6k

**为什么值得关注**：类似沉浸式翻译的开源替代，支持浏览器翻译、pdf、epub 等。需要自定义翻译方式、数据隐私的用户选它没错。
