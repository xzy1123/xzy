## 开源项目 / 工程落地

### Dify – 生产级 Agent 工作流平台
[链接](https://github.com/langgenius/dify) （⭐ 140k+）  
**为什么值得关注**：持续更新的开源 Agent 编排平台，支持可视化搭建 RAG、多 Agent 协作。团队做原型到生产首选。

### NousResearch/hermes-agent – 能“成长”的 Agent
[链接](https://github.com/NousResearch/hermes-agent) （⭐ 135k+）  
**为什么值得关注**：强调 Agent 长期记忆和持续学习，结合知识图谱。适合需要持久化记忆的场景（如客服、个人助手）。

### RAGFlow – 开源 RAG 引擎
[链接](https://github.com/infiniflow/ragflow) （⭐ 79k+）  
**为什么值得关注**：将 RAG 与 Agent 能力融合，支持多数据源、多种检索策略。如果你的知识库查询需要高准确率，这是值得试的框架。

### daily_stock_analysis – LLM 驱动 A/H/美股分析系统
[链接](https://github.com/ZhuLinsen/daily_stock_analysis) （⭐ 34k+）  
**为什么值得关注**：集成行情、新闻、LLM 决策面板，还能自动推送。零成本部署，适合炒股党或量化入门者。

### open-design – 本地优先的开源 Claude Design 替代
[链接](https://github.com/nexu-io/open-design) （⭐ 29k+）  
**为什么值得关注**：直接在本地生成 Web/桌面端 UI 设计，支持 19 个技能和 71 套品牌级设计系统。前端设计师/开发者可用来加速原型。

### promptfoo – 提示词、Agent、RAG 测试与红队工具
[链接](https://github.com/promptfoo/promptfoo) （⭐ 20k+）  
**为什么值得关注**：支持多模型对比、安全测试、漏洞扫描。上线前做质量保障和对抗攻击测试的必备工具。
