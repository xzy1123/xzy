## 🛠️ 新产品 / 新工具

### Agent Builder by Airtop —— 构建“能自愈”的 Agent
[Product Hunt](https://www.producthunt.com/products/airtop)

**为什么值得关注：** 浏览器 Agent 最怕页面变动导致流程断裂。Airtop 的方案是让 Agent 自己检测异常并自我修复。做 RPA 替代方案、网页自动化的团队值得看看它的技术思路。

---

### Grove —— 给人和 AI Agent 共用的终端
[Product Hunt](https://www.producthunt.com/products/grove-8)

**为什么值得关注：** 大多数终端工具是给人用的，Agent 工具是给模型用的。Grove 想做一个“人机共用”的终端，让开发者可以直接在这个界面里指挥 Agent 干活，减少来回切换的摩擦。

---

### Causal —— AI 驱动的可视化项目画布
[Product Hunt](https://www.producthunt.com/products/causal-2)

**为什么值得关注：** 把规划和执行放在一块可视化画布上，AI 辅助生成内容。适合做项目管理、内容策划的团队，可以理解为“AI 版的可视化白板 + 项目工具”。

---

### Tidy —— Mac 上任意应用内免费修语法
[Product Hunt](https://www.producthunt.com/products/tidy-6)

**为什么值得关注：** 端侧 AI 的实用小工具。在任何 Mac 应用里就能用 AI 改语法，不用来回复制粘贴到网页。数据不上云、免费，这个模式值得关注——本地小模型跑通一个单一痛点，也是产品化的好思路。

---

### Blume.codes —— 把编码 Agent 会话沉淀为规则和技能
[Product Hunt](https://www.producthunt.com/products/blume-codes)

**为什么值得关注：** 编码 Agent（如 Cursor、Claude Code）用得多的人都有体会：每次都要重复教它同样的项目规范。Blume 能把 Agent 的完成过程沉淀成可复用的规则和技能，这个方向直击 Agent 落地中的知识积累问题。

---

### Tabbit AI —— 给浏览器“派任务”，不是“问问题”
[Product Hunt](https://www.producthunt.com/products/tabbitai)

**为什么值得关注：** 从“对话式搜索”升级为“任务式执行”，给浏览器一个目标（比如“帮我把这些资料整理成表格”），Agent 自动完成。这是 AI 浏览器插件从问答走向自动化的信号。

## 📦 开源项目 / 工程落地

### mastra-ai/mastra —— TypeScript 时代的 Agent 框架
[GitHub](https://github.com/mastra-ai/mastra) ⭐ 27668

**为什么值得关注：** Mastra 是目前增长最快的 TypeScript Agent 框架之一。如果你的技术栈是 Node.js/TypeScript，又想做 AI 应用和 Agent，这个框架可能是比 Python 方案更顺手的选择。社区活跃、更新频繁。

---

### opensandbox-group/OpenSandbox —— 为 AI Agent 设计的沙箱运行时
[GitHub](https://github.com/opensandbox-group/OpenSandbox) ⭐ 14942

**为什么值得关注：** Agent 执行代码需要安全隔离环境。OpenSandbox 的特点是安全、快、可扩展，相当于给 Agent 一个“干净的临时容器”。做 Agent 平台或自动化工具的同学需要关注沙箱选型。

---

### openvinotoolkit/openvino —— Intel 开源推理优化工具
[GitHub](https://github.com/openvinotoolkit/openvino) ⭐ 10797

**为什么值得关注：** 如果你在 Intel 平台上部署 AI 推理（包括 CPU、核显、NPU），OpenVINO 是绕不开的优化工具。对成本敏感、不想上 GPU 的团队，可以用它把现有模型跑得更快。

---

### strands-agents/harness-sdk —— 让 Agent 可观测、可控制
[GitHub](https://github.com/strands-agents/harness-sdk) ⭐ 7141

**为什么值得关注：** 生产环境的 Agent 不能只靠“prompt 写得好”，需要能从外部观测和控制。Harness-SDK 提供了一套 Python & TypeScript 的工具链，让你对 Agent 做端到端控制。做严肃 Agent 产品的团队建议看看。

---

### IBM/mcp-context-forge —— 统一 AI API 网关
[GitHub](https://github.com/IBM/mcp-context-forge) ⭐ 4413

**为什么值得关注：** 企业里会有多个 MCP Server、A2A、REST/gRPC API，管理越来越乱。IBM 这个项目做一个统一网关层，集中注册和发现。做企业内部 AI 基础设施的同学可以了解。

---

### raullenchai/Rapid-MLX —— Apple Silicon 上最快的本地推理引擎
[GitHub](https://github.com/raullenchai/Rapid-MLX) ⭐ 3646

**为什么值得关注：** 声称比 Ollama 快 4.2 倍，支持 100% 工具调用（Function Calling），还有 prompt cache。如果你的应用需要本地跑模型调工具，这个项目值得关注。
