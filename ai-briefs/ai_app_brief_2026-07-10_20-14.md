**德国电信如何用 AI 重塑电信网络**

- 为什么值得关注：不是 PPT 试点，是真把客服、员工工作流、网络运维都用 Agent 接入了。大企业如果想参考“AI 原生落地”路径，这篇值得细看。

**GPT-5.6 现已成为 Microsoft 365 Copilot 首选模型**
- 链接：https://openai.com/index/gpt-5-6-preferred-model-microsoft-365-copilot
- 为什么值得关注：官方确认 GPT-5.6 提升了 Word、Excel、PPT、Teams 等场景的 Copilot 能力。如果你在做 Microsoft 插件或 Copilot 生态应用，这是底层模型升级的信号。

**GPT-5.6：前沿智能，随你野心扩展**
- 链接：https://openai.com/index/gpt-5-6
- 为什么值得关注：每 token 更多智能，性能/价格比更强。说白了，做应用开发可以用更少的 token 成本拿到更好的结果，对成本敏感的项目很友好。

**ChatGPT 现已成为你最具野心工作的合作伙伴**
- 链接：https://openai.com/index/chatgpt-for-your-most-ambitious-work
- 为什么值得关注：ChatGPT Work 就是一个能跨应用、跨文件行动的 Agent，可以持续几个小时完成一个项目。如果你在处理长流程自动化任务，这值得试试。

**PyTorch 性能分析（第3部分）：Attention 是你需要分析的**
- 链接：https://huggingface.co/blog/torch-attention-profile
- 为什么值得关注：模型推理时 Attention 是瓶颈，这篇教你用 PyTorch 工具具体优化。做模型部署、服务优化的工程师会很感兴趣。

**面向 Agent 的数据**
- 链接：https://huggingface.co/blog/nvidia/open-data-for-agents
- 为什么值得关注：NVIDIA 讲 Agent 需要什么样的数据，对设计数据管线和训练数据策略有参考价值。

## 🔧 开源项目 / 工程落地

**open-design** — 开源 Claude Design 替代品 🎨
- 链接：https://github.com/nexu-io/open-design
- ⭐ 76999 stars
- 为什么值得关注：本地优先的桌面应用，可以直接用 Coding Agent 做原型设计和落地页。前端开发者可以省掉去 Figma 的手动流程。

**mem0ai/mem0** — AI Agent 的通用记忆层
- 链接：https://github.com/mem0ai/mem0
- ⭐ 60544 stars
- 为什么值得关注：Agent 最大的痛点是“记不住”，mem0 帮你解决这个问题。直接集成到 Agent 框架即可，不用从零写记忆模块。

**headroom** — 给 LLM 输入的压缩工具，节省 60-95% tokens
- 链接：https://github.com/headroomlabs-ai/headroom
- ⭐ 58298 stars
- 为什么值得关注：工具输出、日志、文件、RAG 块，在喂给 LLM 之前先压缩。如果你的 API 账单比较高，这个是直接的省钱方案。

**mempalace** — 开源 AI 记忆系统，基准测试最佳
- 链接：https://github.com/MemPalace/mempalace
- ⭐ 57196 stars
- 为什么值得关注：和 mem0 类似但更强调性能，号称在基准测试中领先。对 Agent 记忆有高要求的项目可以对比一下两者。

**cherry-studio** — AI 生产力工作室，自带 300+ 助手
- 链接：https://github.com/CherryHQ/cherry-studio
- ⭐ 48403 stars
- 为什么值得关注：智能聊天 + 自主 Agent + 300 多个预设助手，统一访问主流 LLM。团队想用 AI 提效但没有时间一个个集成 API 的可以用这个。

**oh-my-pi** — 终端上的 AI 编码 Agent
- 链接：https://github.com/can1357/oh-my-pi
- ⭐ 17127 stars
- 为什么值得关注：直接在命令行执行 AI 编码，支持 Python、浏览器、子 agent。对喜欢在终端里完成一切的开发者很对味。
