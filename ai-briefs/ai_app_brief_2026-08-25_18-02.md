## 新产品 / 新工具

**coolplugz：Claude 工作流编排器**
[coolplugz on Product Hunt](https://www.producthunt.com/products/coolplugz)

为什么值得关注：一个帮你编排 Claude 的工具，官方说法是“帮开发者省下大量时间”。如果你已经在用 Claude 做复杂任务，这类编排层工具值得试用。

**Splitsense：AI 用户行为转化分析**
[Splitsense on Product Hunt](https://www.producthunt.com/products/splitsense)

为什么值得关注：把用户行为数据直接转化为转化率提升建议。做增长和产品分析的团队可以看看，本质是拿 AI 替代一部分人工数据分析工作。

**session-indexer：Claude Code 会话历史语义搜索**
[session-indexer on Product Hunt](https://www.producthunt.com/products/session-indexer)

为什么值得关注：对自己的 Claude Code 会话历史做语义搜索。用 Claude Code 写过代码的都懂——会话多了以后翻历史很痛苦，这个工具直接解决痛点。

**Ninjō AI：从 Claude Code 运行的 AI 销售代理**
[Ninjō AI on Product Hunt](https://www.producthunt.com/products/ninjo-ai)

为什么值得关注：在任意渠道上跑 AI 销售代理，基于 Claude Code 驱动。做销售自动化的团队可以关注，特别是已经有 Claude Code 工作流的。

**Nimbia：AI 屏幕共享引导用户上手**
[Nimbia on Product Hunt](https://www.producthunt.com/products/nimbia)

为什么值得关注：AI 通过屏幕共享帮新用户完成 onboarding。对 SaaS 产品来说，这可能会替代一部分人工引导和教学视频的成本。

**Agentcard Purchase API：让 Agent 下单买东西**
[Purchase API by Agentcard on Product Hunt](https://www.producthunt.com/products/agent-card)

为什么值得关注：一个 API 调用，你的 AI Agent 就能在线上完成购买。这是 Agent 从“只会聊天”到“能执行真实交易”的关键基础设施。

## 开源项目 / 工程落地

**unsloth：本地运行和训练 LLM 的 UI**
[unslothai/unsloth on GitHub](https://github.com/unslothai/unsloth) ⭐ 74662

为什么值得关注：支持 Qwen3.8、Kimi K3、MiniMax-H3、Gemma 4、DeepSeek-V4、FLUX 等主流模型，本地 UI 就能跑和训练。对需要私有化部署或微调的团队，这是省 GPU 和时间的利器。

**腾讯 WeKnora：LLM 知识平台**
[Tencent/WeKnora on GitHub](https://github.com/Tencent/WeKnora) ⭐ 20586

为什么值得关注：把原始文档变成可查询的 RAG、自主推理 Agent 和自维护 Wiki，一套工具三用。腾讯开源，中文场景支持成熟，做企业知识库的团队可以直接评估。

**elizaOS/eliza：开源 Agent 操作系统**
[elizaOS/eliza on GitHub](https://github.com/elizaOS/eliza) ⭐ 19164

为什么值得关注：定位是“开源的 agentic 操作系统”，上层应用和底层模型之间的通用层。如果你在搭多 Agent 系统，eliza 的生态和社区值得深入了解。

**presenton：开源 AI 演示文稿生成器**
[presenton/presenton on GitHub](https://github.com/presenton/presenton) ⭐ 9838

为什么值得关注：开源版的 Gamma / Canva / Beautiful AI 替代品，还带 API。擅长用 AI 批量生成 PPT 的团队可以私有化部署，不用担心第三方平台限制。

**Bifrost：号称比 LiteLLM 快 50 倍的企业 AI 网关**
[maximhq/bifrost on GitHub](https://github.com/maximhq/bifrost) ⭐ 7558

为什么值得关注：自适应负载均衡、集群模式、guardrails、支持 1000+ 模型，延迟小于 100 微秒。做 AI 基础设施的团队，网关层的性能和稳定性是刚需，值得拉下来压测验证。

**LangWatch：LLM 评测和 Agent 测试平台**
[langwatch/langwatch on GitHub](https://github.com/langwatch/langwatch) ⭐ 3511

为什么值得关注：专门做 LLM 评测和 AI Agent 测试的开源平台。用大模型做业务逻辑的团队，评测集和回归测试是上线前的必答题，这个项目帮你把这些标准化。
