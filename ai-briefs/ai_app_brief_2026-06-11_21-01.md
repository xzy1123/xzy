## 开源项目 / 工程落地

**nexu-io/open-design** — 本地优先的 Claude Design 替代，原生桌面 App，自带 259+ 技能和 142+ 设计系统。
[GitHub](https://github.com/nexu-io/open-design)  
适合需要离线、强定制设计工具的团队，完全开源。可以理解为 Figma 的本地极速版。

**iOfficeAI/AionUi** — 免费本地 24/7 协作者，支持 OpenClaw、Claude Code、Gemini CLI 等 20+ CLI。
[GitHub](https://github.com/iOfficeAI/AionUi)  
一条命令跑起多个 Agent 做同一个任务，自动协调输出。适合需要多 Agent 并发协作的场景。

**Panniantong/Agent-Reach** — 给 AI Agent 一双“眼睛”看全网，一行 CLI 读 Twitter、B站、小红书等。
[GitHub](https://github.com/Panniantong/Agent-Reach)  
零 API 密钥，直接用 CLI 让 Agent 爬取社交媒体内容。做舆情分析或竞品调研的利器。

**comet-ml/opik** — 开源的 LLM 应用调试、评估、监控平台，支持 tracing 和自动评测。
[GitHub](https://github.com/comet-ml/opik)  
生产环境必备：当你有多条 Chain 和 Agent 时，用它可视化每个步骤的输入输出，快速定位错误。

**Tencent/WeKnora** — 腾讯开源的 LLM 知识平台：文档自动转 RAG、推理 Agent 和自维护 Wiki。
[GitHub](https://github.com/Tencent/WeKnora)  
直接把内部文档扔进去，它就能回答、推理、甚至自动更新知识库。技术团队搭建内部知识问答系统的首选。

**iflytek/astron-agent** — 讯飞开源的商业友好级 Agent 工作流平台，可构建“超级 Agent”。
[GitHub](https://github.com/iflytek/astron-agent)  
企业级：支持多 Agent 编排、人工审核节点、Kubernetes 部署。适合需要严格合规的金融、政务场景。
