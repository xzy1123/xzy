## 开源项目更新

**RAGFlow**（85.5k Stars）
领先的开源 RAG 引擎，融合了 RAG 和 Agent 能力。今天有更新，适合做知识库问答和检索增强生成的团队跟进。
[GitHub](https://github.com/infiniflow/ragflow)

**Open Design**（80.2k Stars）
开源版 Claude Design，本地优先的桌面应用。你的编码 Agent 可以直接变成设计引擎——生成原型、落地页、UI 组件。前端和设计方向的注意了。
[GitHub](https://github.com/nexu-io/open-design)

**Haystack 3.0**（25.9k Stars）
开源 AI 编排框架，今天发布 3.0，重点在 Agent 的 hooks、技能和内省能力。做 LLM 应用编排框架选型的可以关注。
[GitHub](https://github.com/deepset-ai/haystack)

**Vercel AI SDK**（25.6k Stars）
Next.js 团队打造的 AI Toolkit，免费开源，适合 TypeScript 全栈开发者快速搭建 AI 应用。
[GitHub](https://github.com/vercel/ai)

**OpenMed**（4.6k Stars）
本地优先的医疗 AI，支持临床 NER 和 HIPAA PII 脱敏，完全在设备端运行。1000+医疗模型，12种语言，支持 Apple M 芯片。有医疗场景的值得关注。
[GitHub](https://github.com/maziyarpanahi/openmed)

**IBM MCP Context Forge**（4.1k Stars）
IBM 开源的 AI Gateway，统一管理 MCP、A2A 或 REST/gRPC API，提供统一的注册发现和代理能力。适合中大型团队做 API 统一管理。
[GitHub](https://github.com/IBM/mcp-context-forge)
