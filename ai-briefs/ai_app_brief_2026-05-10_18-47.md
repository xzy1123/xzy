**为什么值得关注**：高星项目，Agent 框架持续迭代。适合想快速搭建自主 Agent 的团队。

### zhayujie/CowAgent（原 chatgpt-on-wechat）— 超轻量超级 AI 助理

[链接](https://github.com/zhayujie/CowAgent) | 44,271🌟

**为什么值得关注**：支持微信、飞书、钉钉、企微等国内主流 IM，自带主动思考、任务规划、技能执行和长期记忆。中文社区最活跃的 Agent 项目之一，可直接部署到生产环境。

### nexu-io/open-design — 本地优先的开源设计工具

[链接](https://github.com/nexu-io/open-design) | 35,669🌟

**为什么值得关注**：Anthropic Claude Design 的开源替代，19 个技能，71 个设计系统，本地运行。前端设计师和开发者的实用工具。

### ZhuLinsen/daily_stock_analysis — LLM 驱动智能股票分析

[链接](https://github.com/ZhuLinsen/daily_stock_analysis) | 34,935🌟

**为什么值得关注**：A/H/ 美股行情 + 新闻 + LLM 决策面板 + 多渠道推送，零成本定时运行。个人投资者或量化入门值得参考。

### elizaOS/eliza — 人人可用的自主 Agent

[链接](https://github.com/elizaOS/eliza) | 18,339🌟

**为什么值得关注**：主打“Autonomous agents for everyone”，跨平台 Agent 框架，适合快速原型和 demo。

### langbot-app/LangBot — 生产级多平台机器人开发平台

[链接](https://github.com/langbot-app/LangBot) | 15,998🌟

**为什么值得关注**：提供 Agent、知识库编排、插件系统，支持 Discord / Slack / LINE / Telegram 等，适合想在飞书或企微上做 bot 的团队。
