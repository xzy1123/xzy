## 官方产品 / 平台

**ChatGPT Wallet 上线**
[Introducing ChatGPT Wallet](https://openai.com/index/introducing-chatgpt-wallet)
Agent 在 ChatGPT Work、Codex、dots 里可以替用户完成购买，需要用户批准。**值得关注**：Agent 从“帮你查”走到“帮你付”，支付授权和风控会变成落地时必须解决的问题。

**Shield 用 Agent 接手老旧门户操作**
[Shield helps technicians hand off legacy portal work](https://openai.com/business/customer-stories/shield)
IT 技术员的重复门户操作交给 Forge Agent 去点。**值得关注**：这是很典型的“老系统没有 API，只能靠 Agent 点界面”场景，很多企业内部都有类似需求。

**Amplitude 用 Agent 做到 1–2 天发一次改进**
[How Amplitude ships product improvements in 1–2 days](https://openai.com/business/customer-stories/amplitude)
产品 Agent Wave 负责找该做什么，再配合编码工具落地。**值得关注**：从“发现问题”到“改完上线”串成一条链，是产品团队可以借鉴的流程样板。

**Gondola 用 Codex 把主工程师产出拉高 50%**
[Gondola doubles revenue as its team builds more with Codex](https://openai.com/business/customer-stories/gondola)
小团队靠编码 Agent 撑起更多开发量。**值得关注**：小团队评估编码工具 ROI 时，这类案例比 benchmark 更直观。

**用 SimReady 资产搭机器人抓取仿真**
[Build a Robot Pick-and-Place Simulation with SimReady Assets](https://huggingface.co/blog/nvidia/simready-assets-robot-pick-and-place)
**值得关注**：仿真环境搭建一直是机器人落地的门槛，现成资产能省不少前期工作。

**XYBench：关注问题背后的问题**
[XYBench: Helping with the problem behind the question](https://huggingface.co/blog/allenai/xybench)
**值得关注**：评测开始盯“用户没说明白的真实意图”，这对做对话产品和 Agent 任务理解的人有参考价值。

## 新产品 / 新工具

**Kokonut UI**
[Kokonut UI](https://www.producthunt.com/products/kokonutui)
开源的 AI Agent UI 组件。**值得关注**：Agent 产品的前端不用每次从零搭，能加快原型速度。

**Dex Semantics**
[Dex Semantics](https://www.producthunt.com/products/dex-by-exmergo)
让 Agent 做数据分析，号称错误少 25%。**值得关注**：数据分析是 Agent 最容易出错的场景之一，准确率提升直接关系到能不能交给业务用。

**Thunder**
[Thunder](https://www.producthunt.com/products/thunder-3)
面向 AI 负载的持久化 key-value 数据库，主打快。**值得关注**：Agent 应用的状态存储和缓存是个实际工程问题。

**Gemini Robotics 2.5**
[Gemini Robotics 2.5](https://www.producthunt.com/products/gemini-robotics-2-5)
Google 目前能力最强的机器人模型。**值得关注**：机器人模型迭代很快，做具身智能选型时要持续跟。

**CodeMesh**
[CodeMesh](https://www.producthunt.com/products/codemesh-2)
号称把 AI 编码成本砍 90%。**值得关注**：编码 Agent 用多了账单很痛，降本方案值得试。

**HiringNow**
[HiringNow](https://www.producthunt.com/products/hiringnow)
自动找职位并投递的求职 Agent。**值得关注**：典型的“替人跑流程”Agent，也能看出招聘方会怎么应对批量投递。

## 开源项目 / 工程落地

**hermes-agent**
[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
主打“随你成长”的 Agent。**值得关注**：Agent 框架同质化严重，重点看它的记忆和扩展设计是否适合自己的场景。

**paperclip**
[paperclipai/paperclip](https://github.com/paperclipai/paperclip)
管理工作中多个 Agent 的开源应用。**值得关注**：Agent 一多，调度和权限管理就成了刚需，这类工具会越来越常用。

**headroom**
[headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom)
在内容进 LLM 前压缩工具输出、日志、文件和 RAG 片段，编码 Agent 少 20% token，JS 相关场景号称少 60–95%。**值得关注**：直接省钱，接入成本也不高，成本敏感团队可以优先试。

**qwen-code**
[QwenLM/qwen-code](https://github.com/QwenLM/qwen-code)
跑在终端里的开源编码 Agent。**值得关注**：终端编码 Agent 选择变多，国内模型生态也多了一个可选项。

**dsh-Go**
[ccch1mneyyy/dsh-Go](https://github.com/ccch1mneyyy/dsh-Go)
把 DeepSeek Harness 装进手机，本机运行，也能遥控电脑。**值得关注**：移动端跑 Agent 是个有意思的方向，适合做远程任务触发。

**LangBot**
[langbot-app/LangBot](https://github.com/langbot-app/LangBot)
生产级多平台智能机器人开发平台，支持 Discord / Slack / LINE / Telegram / 微信等，带知识库和插件系统。**值得关注**：要做一个跨平台 IM 机器人，这套能省掉大量适配工作。
