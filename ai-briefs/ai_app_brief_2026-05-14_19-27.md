## 官方产品 / 平台更新

### 为 Codex 在 Windows 上构建安全高效的沙箱
[Building a safe, effective sandbox to enable Codex on Windows](https://openai.com/index/building-codex-windows-sandbox)  
🔍 为什么值得关注：Codex 是 OpenAI 的编程 Agent，这次专门为 Windows 做了沙箱隔离，控制文件访问和网络，让 Agent 能安全干活。对需要使用自动化工作流（尤其 Windows 环境）的团队来说，这是现成的安全框架参考。

### 关于 TanStack npm 供应链攻击的回应
[Our response to the TanStack npm supply chain attack](https://openai.com/index/our-response-to-the-tanstack-npm-supply-chain-attack)  
🔍 为什么值得关注：供应链攻击是 AI 产品必须面对的威胁，OpenAI 公开了应对措施，包括签名验证等。做 Agent 或依赖 npm 包的项目，可以抄作业。

### 财务团队如何使用 Codex
[How finance teams use Codex](https://openai.com/academy/how-finance-teams-use-codex)  
🔍 为什么值得关注：Codex 不止写代码，还能帮财务团队自动生成报表、检验模型、做预算场景。非技术团队也能用 AI 提效，这个案例很落地。

### NVIDIA 工程师和研究者如何用 Codex 开发
[How NVIDIA engineers and researchers build with Codex](https://openai.com/index/nvidia)  
🔍 为什么值得关注：NVIDIA 团队用 Codex + GPT-5.5 把研究想法快速变成可运行实验，甚至直接上生产。这是最一线的 Agent 工程实践案例。

### AWS 上训练和推理基础模型的构建块
[Building Blocks for Foundation Model Training and Inference on AWS](https://huggingface.co/blog/amazon/foundation-model-building-blocks)  
🔍 为什么值得关注：AWS 和 Hugging Face 合作，给出一套可重复用的基础设施组件。想用 AWS 自建/托管模型训练推理的团队，别自己造轮子了。

### EMO：通过混合专家预训练实现涌现模块化
[EMO: Pretraining mixture of experts for emergent modularity](https://huggingface.co/blog/allenai/emo)  
🔍 为什么值得关注：MoE 架构在训练中自动分工，不同专家管不同任务。这意味着未来模型可以更高效、更灵活，对下游应用（如多任务 Agent）是利好。

## 开源项目 / 工程落地

### vllm – 高性能 LLM 推理引擎
[vllm-project/vllm](https://github.com/vllm-project/vllm) ⭐ 79,988  
🔍 为什么值得关注：依然是部署大模型的标配引擎，支持高吞吐、低显存。如果你的服务还在用慢推理，换 vllm 是性价比最高的优化。

### unsloth – 本地训练和运行模型的 Web 界面
[unslothai/unsloth](https://github.com/unslothai/unsloth) ⭐ 64,222  
🔍 为什么值得关注：Unsloth Studio 让非技术用户也能微调开源模型（Gemma 4、Qwen3.6 等）。适合做私有化部署或小白入门微调。

### open-design – 本地优先的开源设计工具
[nexu-io/open-design](https://github.com/nexu-io/open-design) ⭐ 39,852  
🔍 为什么值得关注：Claude Design 的开源替代，支持 19 种技能、71 个品牌设计系统。给 AI 生成 UI 的前端团队提供了可扩展的底层。

### OpenViking – 专为 AI Agent 打造的上下文数据库
[volcengine/OpenViking](https://github.com/volcengine/OpenViking) ⭐ 23,903  
🔍 为什么值得关注：火山引擎开源，统一管理 Agent 的上下文。如果你在构建多步推理 Agent，这个数据库能帮你解决历史记忆和持久化。

### activepieces – AI Agent + MCP 工作流自动化
[activepieces/activepieces](https://github.com/activepieces/activepieces) ⭐ 22,182  
🔍 为什么值得关注：自带约 400 个 MCP 服务器，可以直接编排 AI 工作流。相当于 Zapier 的开源 + AI 版，适合做自动化运维或内部工具。

### OpenCLI – 把任意网站、桌面应用变成 CLI
[jackwener/OpenCLI](https://github.com/jackwener/OpenCLI) ⭐ 20,527  
🔍 为什么值得关注：AI 原生运行时，让 Agent 能直接调用网页、Electron 应用甚至本地二进制。对想把非 API 能力接入 Agent 的团队是神器。
