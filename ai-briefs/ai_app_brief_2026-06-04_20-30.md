## 新产品 / 新工具

**Perplexity Personal Computer for Windows**
- 链接：https://www.producthunt.com/products/perplexity-personal-computer-for-windows
- 为什么值得关注：AI 能直接操作你电脑里的文件和应用了 —— 不是云端，是本地。对普通用户是“我的 AI 能帮我写周报”，对开发者则是“AI Agent 也能操作我的桌面 CRM / 数据库”。原生 Windows 支持，入口更宽。

**Keen Code：节省上下文的 CLI 编码 Agent**
- 链接：https://www.producthunt.com/products/keen-code-a-cli-coding-agent
- 为什么值得关注：关键词是“上下文高效”。很多人在实际用 AI 编码时面临的痛点是 —— 超长上下文太贵、太慢。Keen Code 从 CLI 切入，专门优化 token 使用效率，对高频开发者是刚需工具。

**DotBGE：本地优先、AI Agent 友好的文件加密**
- 链接：https://www.producthunt.com/products/dotbge
- 为什么值得关注：当 AI Agent 开始读写你的文件，安全就成了第一道门槛。这个工具主打本地加密 + Agent 兼容 —— 说白了，让你放心地对 Agent 说“帮我把文件加密再上传”。

**Extella.AI：会“进化”自己的 Agent 平台**
- 链接：https://www.producthunt.com/products/extella-ai
- 为什么值得关注：不止是封装模型。这个平台的特点是“Agent 能自我迭代、构建可复用的系统”。对团队而言，不是在写一次性脚本，而是在养一个越来越聪明的工作流引擎。

**Deliveryman.ai：冷邮件自动化**
- 链接：https://www.producthug.com/products/deliveryman-ai
- 为什么值得关注：不需要 Gsuite，就能自动化冷邮件基础设施。对于销售、市场团队或独立创业者，这是直接把 AI 变成一个“电话销售员”的轻量方案。

**Empromptu AI：用你现有的 App 数据微调模型**
- 链接：https://www.producthunt.com/products/empromptu
- 为什么值得关注：它说“你正在构建的 AI 应用数据，就可以直接用来训练自己的微调模型”。对想做私有模型但没有数据工程师的团队来说，这个思路降低了门槛 —— 用已有产品产出高质量训练数据。
