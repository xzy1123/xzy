## 📰 官方产品 / 平台更新

### 马耳他全国普及 ChatGPT Plus
- 链接：https://openai.com/index/malta-chatgpt-plus-partnership
- **为什么值得关注**：这是国家级AI素养计划的落地案例。政府买单，让所有公民用上 GPT-5 级别能力，直接推动全民 AI 技能培训，为其他国家的教育/政务应用提供了参考范式。

### 业务运营团队如何使用 Codex
- 链接：https://openai.com/academy/codex-for-work/how-business-operations-teams-use-codex
- **为什么值得关注**：别把 Codex 当代码工具。官方给出了它在**写战略汇报、决策简报、进度更新**等非技术场景的用法，内部知识管理可以直接模仿。

### Databricks 引入 GPT-5.5 做企业 Agent 工作流
- 链接：https://openai.com/index/databricks
- **为什么值得关注**：大厂背书。GPT-5.5 在 **OfficeQA Pro 企业办公知识问答基准**上拿了 SOTA，说明 Agent 在办公自动化（审批、查询、报告）场景已具备实用价值。

### 数据科学团队如何使用 Codex
- 链接：https://openai.com/academy/codex-for-work/how-data-science-teams-use-codex
- **为什么值得关注**：从**根因分析、影响报告、KPI 备忘录到仪表盘说明**，Codex 可以自动化数据团队最烦的文字产出，建议你们的数据分析师也试试。

### Granite Embedding Multilingual R2：首个 Apache 2.0 的 32K 上下文多语言向量模型
- 链接：https://huggingface.co/blog/ibm-granite/granite-embedding-multilingual-r2
- **为什么值得关注**：**开源、多语言、32K 长上下文、参数小于1亿**，这几个标签组合起来，对中文 RAG 和搜索系统是个好消息。免费用，效果好，值得立刻测试。

### 连续批处理中的异步优化
- 链接：https://huggingface.co/blog/continuous_async
- **为什么值得关注**：做模型推理服务的人必看。讲如何**优化连续批处理的异步机制**，直接关系到 GPU 利用率和并发吞吐，是工程落地的关键细节。

## 🛠️ 新产品 / 新工具

### AgentMemory：给 AI 编程助手加上持久记忆
- 链接：https://www.producthunt.com/products/agent-memory-dev
- **为什么值得关注**：**Claude Code、Codex 等编程 Agent 用完就忘**。这个工具让它们能记住项目上下文、过往决策，避免重复犯错。适合所有重度使用 AI 编程的团队。

### Loova Agents：你的 AI 视频导演
- 链接：https://www.producthunt.com/products/loova-agents
- **为什么值得关注**：理念很有趣：**AI Agent 协调生成电影级视频**。它负责拆解脚本、选角色、分镜，如果你在做 AI 视频生成工作流，可参考其 Agent 编排思路。

### Gemini 3.1 Flash-Lite：轻量级模型用于高并发管线
- 链接：https://www.producthunt.com/products/gemini-3-1-flash-lite-2
- **为什么值得关注**：**薄、快、便宜**。适合大规模批量推理（如内容审核、数据标注），如果你的管线对成本敏感，这个模型值得评估。

### Standboy：Agent 工作时让你“摸鱼”的游戏机
- 链接：https://www.producthunt.com/products/standboy
- **为什么值得关注**：一件“硬核摸鱼”玩具。它在 Agent 运行时实时反馈进度，开发者可以一边玩一边看任务跑完没有，体现了 **Agent 工作流需要新的人机交互界面**。

### Kimi WebBridge：让 AI Agent 连接实时网页
- 链接：https://www.producthunt.com/products/kimi-ai-assistant
- **为什么值得关注**：**Agent 的“眼睛”**。它能打通 Agent 和实时网页的桥梁，让 Agent 能获取、理解网页内容并采取行动。如果做信息采集或网页自动化，这个思路很关键。

### OpenHuman：以人为本的开源 AI 工具架
- 链接：https://www.producthunt.com/products/openhuman
- **为什么值得关注**：重点在 **“人本设计”** 。它提供一个中间层，让开发者更容易构建 **AI 安全、可控、可追溯**的应用，符合当前对 AI 治理的关注趋势。

## 📂 开源项目 / 工程落地

### elizaOS/eliza（⭐ 18.3k）
- 链接：https://github.com/elizaOS/eliza
- **为什么值得关注**：一个承诺“**为所有人提供自主Agent**”的框架。起步快、热度高，适合快速实验各种 AI Agent 场景，是搭建个人 Agent 的好起点。

### vespa-engine/vespa（⭐ 6.9k）
- 链接：https://github.com/vespa-engine/vespa
- **为什么值得关注**：**AI + 数据在线检索**的老牌强者。对于要做高维向量搜索、实时推荐、语义问答系统的团队，它仍是生产级的可靠选择。

### cactus-compute/cactus（⭐ 4.9k）
- 链接：https://github.com/cactus-compute/cactus
- **为什么值得关注**：专为**手机和穿戴设备**设计的极低延迟 AI 引擎。如果你的应用需要端侧 AI 推理（如实时翻译、语音助手），这个可以大幅降低设备和云的成本。

### PurpleAILAB/Decepticon（⭐ 3.8k）
- 链接：https://github.com/PurpleAILAB/Decepticon
- **为什么值得关注**：**红队自动化攻击 Agent**。虽然名字有点中二，但它是安全领域 Agent 工程化的案例，可用于自动化渗透测试，属于“以毒攻毒”的应用。

### langchain-ai/langgraphjs（⭐ 2.9k）
- 链接：https://github.com/langchain-ai/langgraphjs
- **为什么值得关注**：LangChain 的 JS 版**Agent 图框架**。如果你用 JS/Node.js 栈，且 Agent 流程复杂（多分支、多步骤、有状态），这是最成熟的框架之一。

### ArcReel/ArcReel（⭐ 2.2k）
- 链接：https://github.com/ArcReel/ArcReel
- **为什么值得关注**：**AI Agent 驱动的视频生成工作台，开源！** 能走通“小说→角色/场景设计→剧本→分镜→视频”全链路，且保证跨镜头角色一致。对做 AI 短视频、数字人内容生产的团队，可直接拿来用。
