## 官方产品 / 平台更新

**OpenAI 推出 AI Futures 博客**
链接：https://openai.com/index/introducing-ai-futures

OpenAI 新开了一个博客，专门讨论 transformative AI 对权力、治理、经济和个体自由的影响。这类内容不会直接给你一个能用的工具，但值得关注的是 OpenAI 开始主动引导“AI 之后怎么办”的公共讨论，这对你判断行业方向和政策风向有参考价值。

**Stampli 用 ChatGPT Work 把上线时间缩短 68%**
链接：https://openai.com/index/stampli

Stampli 在设计和资源都卡死的情况下，用 Codex 加 ChatGPT Work 把原本数周的发布准备工作压缩到很短。这是一个很实在的工程提效案例：不是“AI 能写代码”这种泛泛的说法，而是具体到固定截止日期下如何用 AI 把流程压下来。

**OpenAI 为前沿模型提供零数据保留选项**
链接：https://openai.com/index/offering-zero-data-retention-for-frontier-models

OpenAI 重申对符合条件的 API 客户提供零数据保留（ZDR），并预告了 Private Safety Processing 功能。简单说就是在不牺牲安全审查的前提下，你的数据不会被存下来。做企业应用的朋友可以关注这条，数据合规一直是上车的门槛。

**Replit 用 GPT-5.6 Luna 扩大软件创建入口**
链接：https://openai.com/index/replit

Replit 推出 Free Mode，由 GPT-5.6 Luna 驱动，任何人不用考虑 token 成本就能把想法变成能跑的软件。等于把“AI 写软件”的门槛又降了一截。对独立开发者和非程序员来说，这是值得上手试一下的变化。

**衡量语音识别中的 benchmark 优化**
链接：https://huggingface.co/blog/asr-benchmark-optimization

Hugging Face 发了篇文章，讨论语音识别模型在 benchmark 上的优化怎么衡量。对做语音相关应用的人来说，这篇文章能帮你判断一个模型是真变强了还是只在刷榜。

**LFM2.5-DSpark 推理最高提速 3.2 倍**
链接：https://huggingface.co/blog/LiquidAI/lfm25-dspark

Liquid AI 发布了 LFM2.5-DSpark，号称推理速度最高提升 3.2 倍。如果你在跑大模型推理，速度就是成本，这类优化值得盯一下。

## 新产品 / 新工具

**Construct Computer —— AI 同事有电脑了**
链接：https://www.producthunt.com/products/construct-computer

主打概念是“你的 AI 同事有了一台电脑，你把白天拿回来”。本质上是一个 AI 工作代理，帮你操作软件、处理杂事。值得关注的是这类“AI 拥有自己的操作环境”的产品形态越来越多了。

**Claude Academy —— Anthropic 官方学习中心**
链接：https://www.producthunt.com/products/claude-academy

Anthropic 官方的 Claude 学习平台上线。如果你在用 Claude 或打算深入使用，官方出的教程通常比零散的网络教程更系统，值得收藏备用。

**FetchSandbox MCP —— 验证 AI 集成修复的 MCP**
链接：https://www.producthunt.com/products/fetchsandbox

这个 MCP 工具用来验证 AI 做的集成修复是否真的有效。做 AI 自动化测试或 CI/CD 的朋友可以看看，省得每次让 AI 改完代码还要手动验证一遍。

**SubtitleGenerator —— 一键从视频到可用字幕**
链接：https://www.producthunt.com/products/subtitlegenerator

在浏览器里完成视频到“可发布字幕”的全流程。做内容生产的同学，这是实打实的效率工具，省掉剪映里手动校对的那一步。

**Zero —— Vercel 为 AI Agent 设计的编程语言**
链接：https://www.producthunt.com/products/zero-15

Vercel 发布了一门专为 AI Agent 设计的编程语言。如果 Vercel 要押注这个方向，说明 Agent 原生开发正在成为基础设施层面的需求，做前端的可以关注一下这门语言的设计思路。

**AutoClaw —— 跨桌面、浏览器和聊天的 AI 工作代理**
链接：https://www.producthunt.com/products/z-ai

一个横跨桌面、浏览器和聊天的 AI 工作代理。和 Construct Computer 类似，这类“Agent 接管整个工作环境”的工具正在批量出现，值得体验一下看看是不是真的能省时间。

## 开源项目 / 工程落地

**CherryHQ/cherry-studio**（⭐ 50.9k）
链接：https://github.com/CherryHQ/cherry-studio

AI 生产力工作台，集成了智能聊天、自主 Agent 和 300+ 助手，统一接入主流大模型。五万星说明社区认可度很高。如果你在多款模型之间来回切换，这个项目能帮你把入口统一起来。

**Anil-matcha/Open-Generative-AI**（⭐ 26.9k）
链接：https://github.com/Anil-matcha/Open-Generative-AI

开源的 AI 图片和视频生成平台，集成了 500+ 模型（Flux、Midjourney、Kling 等）。不想被某个平台的订阅费绑住的话，这个可以作为自建方案的参考。

**elizaOS/eliza**（⭐ 19.1k）
链接：https://github.com/elizaOS/eliza

开源的 agentic operating system，简单理解就是给 AI Agent 用的操作系统层。Star 数涨得很快，做 Agent 开发的同学值得关注它的架构设计。

**gptme/gptme**（⭐ 4.4k）
链接：https://github.com/gptme/gptme

在终端里跑的 AI Agent，能写代码、操作终端、浏览网页。适合喜欢命令行工作流、不想离开终端窗口的开发者。自托管意味着数据不出本地，隐私上有优势。

**neomjs/neo**（⭐ 3.3k）
链接：https://github.com/neomjs/neo

定位很特别：一个“自我进化的软件有机体”，跨模型 swarm 直接住在你的应用里。简单说就是 AI 开发团队嵌入到 app 里帮你持续迭代。概念比较超前，适合关注 AI 工程化前沿的人看看。

**LetsFG/LetsFG**（⭐ 1.8k）
链接：https://github.com/LetsFG/LetsFG

Agent 原生的机票和酒店搜索预订工具，提供 MCP server、CLI 和 Python/JS SDK。覆盖几百家航空公司和主流预订平台。这是 MCP 在生活服务场景的一个实际落地案例，做 Agent 应用的同学可以参考它的接入方式。
